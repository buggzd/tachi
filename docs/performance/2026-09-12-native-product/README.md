## 已完成的实机观察

- 已保存账号正常恢复；实际 Jellyfin 1080p HEVC 10-bit MKV 在 2D 下直放，
  解码器 `c2.qti.hevc.decoder`，HTML video 数量为 0。
- 实际 ASS 双语字幕、附加位置文字与原生画面同时显示。暂停时从简体 ASS 切到繁体 ASS，
  切换前后原生时钟均为 1142.594 秒，仍暂停且没有字幕加载错误。
- 外接 3840×1080 SBS 使用 `c2.qti.avc.decoder` 播放实际 Jellyfin H.264/AAC MP4。
  两眼视频、控制层、视频信息可见，页面仍无 HTML video。
- 中途开启实时 3D 暴露并修复了延迟创建后端的引用问题；修复包已在手机验证，
  QNN 就绪后持续产生有效深度，左右眼出现实际 GPU 深度预览。
- 已返回样本中，453 次深度更新后暂停，18 秒后有效深度仍保留。运行中的视频信息截图里解码掉帧计数为 0。
- HyperOS 在物理 SBS 切换后仍会禁用外接屏；恢复系统输出后 SBS 才确认生效。
  这是现存系统限制；此次没有验证该过程中的完整播放连续性。

一条运行中样本（110 次深度更新，含此前平面渲染的 GPU 统计）为：

| 阶段 | 均值 | P95 |
| --- | ---: | ---: |
| RGBA → CHW | 1.001 ms | 1.884 ms |
| QNN 推理及输出读取 | 18.363 ms | 19.531 ms |

这些是调试过程中读取的滚动摘要，并非固定时长、相同片源的严格性能 A/B。

## 用户回传清单

安装后按实际使用顺序测试即可：

1. 新增自定义服务器：打开地址输入、提交、返回，确认原有账号不丢失。
2. 2D 与 SBS 各看一段；SBS 中启停实时 3D，开启视频信息确认深度图持续变化。
3. 暂停、前后 seek、退出续播、上一集/下一集；确认没有重复声音或位置重置。
4. 多音轨片源切轨；ASS/SSA、普通文字、位图字幕分别测试，检查字幕同步及眼间位置。
5. 原本需要转码的片源播放与恢复；检查 Jellyfin HLS、HDR 转 SDR 的实际结果。
6. 后台再回来：应恢复原位置并暂停；断开/重连及系统允许镜像后检查画面。

异常后在**手机设置 → 分享诊断日志**导出，并说明操作顺序、2D/SBS、是否开启实时 3D。
请在强制结束应用前导出；报告不持久化到下次进程。深度模型不是逐视频帧运行，
12 Hz 是采样目标，视频仍由原生播放器按媒体时钟播放。

本轮没有完成多音轨/HLS/位图字幕的最终实机回归、全部编码、4K/60、长时热态、
精确媒体 PTS 对齐或主观眼镜舒适度验收。不要将这些项目称为全部通过。
