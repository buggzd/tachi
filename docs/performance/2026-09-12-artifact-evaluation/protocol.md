# SBS 伪影量化协议（优化前冻结）

基线：`3560807` 的 Java `TemporalDepth`。固定 266×154、12 Hz、每眼 1920 像素、视差系数 0.016；不得通过减小立体强度或每帧真值对齐改善得分。

本轮首先隔离深度稳定器：输入已知真值的合成逆深度及 RGBA，执行实际 Java 类，比较量化后的 R8 输出。空间真值固定于 [0,1]，两侧各至少 5% 的 0/1 锚区使 P5/P95 不改变真实尺度。统计区域不含锚区；暖机 8 帧后评价。

- 位移误差：`1920 × .016 × |d_hat - d_gt|`，单眼像素单位；报告 MAE/P95。
- 轮廓带误差：在真值轮廓左右各 2 个模型像素内单独统计。
- 新露出区域误差：前帧前景、当前背景的真值掩码；报告残余前景深度引起的位移误差。
- 时序变化误差：`30.72 × |(d_hat[t]-d_hat[t-1]) - (d_gt[t]-d_gt[t-1])|`。这是本项目的参考变化误差，不冒称 TAE、tOF 或 tLP。
- 运动响应：真实深度阶跃达到 90% 所需更新数；静止误差与响应时间必须一起读。
- 真实片段没有真值，只允许报告光流可信区的变化、覆盖率及深度对比度等代理量；不得把模型深度当几何真值。

预置场景：静止噪声、移动浅轮廓、移动强轮廓、相同颜色遮挡、亮度阈值扰动、深度阈值扰动、真实深度阶跃、切镜。开发种子 20260912；保留种子 73019、98173，参数选定后才评估保留集。

首轮候选：连续历史置信度、当前局部范围裁剪历史，以及二者组合。分别消融；不改变模型、分辨率、采样率或渲染视差。采用门槛：移动浅轮廓/露出误差至少一项降低 20%，普通静止噪声 MAE 不恶化超过 5%，阶跃响应不得更慢一帧以上；其他场景退化必须逐项披露。若失败则不采用该候选。

这不是眼镜画质验收，也不是完整 RGB 新视点合成指标。渲染器填洞、深度/颜色时间错位及 QNN 量化误差另测；不得从深度位移误差推断整个 SBS 画面改善百分比。
