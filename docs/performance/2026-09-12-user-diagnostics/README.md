## 原生 / 深度测量

报告中一段持续 playing 的 58.757 秒区间，位置从 42.208 到 100.972 秒，
深度计数从 35 到 727、解码计数从 495 到 1899；差分得到 **11.78 次深度/秒、23.90 解码帧/秒**。
后面的 78.798 秒区间（含两条 buffering 及位置跳变）深度计数 168→1111、解码计数 780→2660，
总体吞吐为 11.97 Hz / 23.86 fps，不能称为一段无 seek 的连续播放。

接近最后暂停前的一条样本，其滚动窗口统计如下；P95 是该窗口已有统计，不是对导出均值再计算的分位数：

| 阶段 | 均值 ms | P95 ms |
| --- | ---: | ---: |
| NPU 推理 | 18.37 | 19.39 |
| CPU 时序稳定 | 20.05 | 24.02 |
| 采集至深度上传 | 60.39 | 68.75 |
| GPU 绘制 | 7.67 | 7.76 |

深度采集/上传链与 GPU 渲染异步重叠，不能将所有统计直接相加。GPU 计时不含系统合成，
视频解码丢帧 0 不证明外屏每个刷新周期都有新帧；约 12 Hz 为目前设定的深度采样目标。
CPU 稳定和读回仍有优化空间，但本报告不能证明它们导致 MyGO 播放失败。

已补齐独立事件/失败队列、匿名 attempt/source 次序、错误阶段、准备请求 HTTP 状态码、
统一时钟和完整显示几何 JSON；后续复现应使用新格式报告。此改动不宣称修复 MyGO 的未知根因。

## APK 大小

同一份源码、ARM64、本地 Debug 签名及未签名 Release/R8 构建，单位 MiB：

| 类型 | Lite | Full |
| --- | ---: | ---: |
| Debug | 25.73 | 100.97 |
| Release（本地未签名） | 21.27 | 92.26 |

Release Lite 比 Full 小约 77%。Lite 移除模型和 QNN/ORT，保留原生 2D、平面 SBS、字幕和全部界面；
Full 保留已验证的模型/厂商库，库字节不 strip。正式签名只会增加少量签名数据，以上不是已发布资产。

旧的已交付 Full Debug APK 为 115.82 MiB，其中 ZIP 有效压缩载荷约 100.94 MiB，
其余约 14.88 MiB；首次增量切换到 Lite 后 APK 仍有 97.07 MiB，而有效载荷只有 25.70 MiB。
重建 APK 容器后开销约 0.03 MiB，证明有大量无引用旧 ZIP 数据残留。构建脚本现会重新生成
选定的 APK 文件，并拒绝异常 ZIP 开销，避免小版本只在目录列表上移除了模型。

Full 包体较大的实际载荷包括 QNN HTP Prepare（约 36 MiB）、模型（约 19 MiB）及字幕字体（约 13 MiB）。
字体保留完整字幕覆盖；移除 HTP Prepare 需要改变在线建图方式并重新实机验证，不在本轮贸然删库。
