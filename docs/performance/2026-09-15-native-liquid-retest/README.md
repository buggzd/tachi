## 阻塞与剩余验收

高动态原片打开后进入 `error`，日志记录 H.264 `avc1.6E0028`、1920×1080、30 fps、10-bit，`format_supported=NO_EXCEEDS_CAPABILITIES`，解码器 `c2.qti.avc.decoder` 失败。该路径没有产生有效成对帧，不能拿兼容素材代替高动态原片的 347/579 帧画质验收。后续应准备设备支持的同内容编码版本并记录转换和 PTS 对应关系。

正式 Jellyfin 播放器最后一次恢复截图仍为黑色视频区域和“正在准备实时 3D”，控制栏位置为 10:37。该证据说明此次恢复尝试没有得到可供验收的播放画面；不能仅凭截图定位为 USB、解码或缓存错误，也不能证明前面所有尝试均失败。应从这个状态做一次有界诊断，不继续重复焦点导航。

显示生命周期尚缺完整的动作→Activity→display→USB 对照，不能宣布镜像确认根治。ASS/WebVTT、独立音频口型、缓存跨 seek/代际/几何失效及有效连续 20–30 分钟均未验收；详见[测试矩阵](test-matrix.md)。保留修订版为实验构建，不据此更换默认策略。
