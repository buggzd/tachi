# SBS 伪影的评价方法与首轮优化依据

日期：2026-09-12。基线：`3560807`。研究对象是单目视频深度驱动的 SBS，不是游戏引擎的超分辨率。本轮先建立[固定实验协议](../performance/2026-09-12-artifact-evaluation/protocol.md)，再测试 Java 稳定器，结果与采用范围见[实测报告](../performance/2026-09-12-artifact-evaluation/README.md)。

## 论文中有哪些可用指标

| 来源 | 如何评价 | 对 tachi 的适用范围及限制 |
| --- | --- | --- |
| [Video Depth Anything，CVPR 2025](https://arxiv.org/html/2501.12375v2)，§4 与附录 Evaluation metric details | 整个视频逆深度统一拟合 scale/shift，转换为深度后测 AbsRel、δ1；相邻帧双向重投影测 Temporal Alignment Error（TAE） | 有真值深度、相机参数和有效重投影区域时才能按论文计算。每帧单独对齐会隐藏尺度漂移；当前动画和普通电影没有这些真值 |
| [The Unreasonable Effectiveness of Deep Features as a Perceptual Metric，CVPR 2018](https://richzhang.github.io/PerceptualSimilarity/) | LPIPS：比较参考图与待测图的深层特征距离，比像素误差更接近部分感知差异 | 可用于有真值的新视点图像；单帧 LPIPS 不能独立衡量鬼影或抖动，源 2D 图也不是左右眼真值 |
| [TecoGAN，ACM TOG 2020](https://arxiv.org/abs/1811.09393)，[官方 metrics.py](https://github.com/thunil/TecoGAN/blob/master/metrics.py) | 同时报告 PSNR、LPIPS、tOF、tLP。tOF 比较输出与真值各自的相邻帧光流；tLP 比较两条序列各自的相邻帧 LPIPS 变化 | 避免只奖励平滑/冻结；需要真值视频。官方代码 tOF 是光流向量差的 L2 长度平均，tLP100 是两个 LPIPS 距离之差的绝对值乘 100；不是简单的前后帧差 |
| [ColorVideoVDP，SIGGRAPH 2024](https://doi.org/10.1145/3658144)，[官方实现说明](https://github.com/gfxdisp/ColorVideoVDP) | 同时考虑时空、颜色和显示条件的全参考感知评价，输出 JOD 与误差图 | 适合最终 RGB 视频感知评估；需正确的显示/观看参数和参考视频，不能把默认桌面配置的分数当 RayNeo 实测舒适度 |

没有一个论文分数等同于通用“鬼影合格标准”，也没有可直接套用到本产品的统一合格像素阈值。以上为研究指标，不是产品认证标准。本轮没有安装 LPIPS/ColorVideoVDP 权重或声称跑过上述完整指标；缺少真值和显示校准时不伪造分数。

## 如何把指标转换为我们能验证的量

当前 shader 单眼水平位移为 `s = eye × (d - 0.5) × 0.016 × 1920`。因此归一化逆深度误差 0.01 对应单眼约 0.3072 像素的位移误差。左右眼相对视差误差是其两倍；输出宽度或立体强度改变时须重新换算。这比“深度图好像更平滑”更容易解释。

评价必须同时看以下维度：

1. **空间正确性**：相对真值的位移 MAE/P95；轮廓带和新露出区域分别测，避免大面积背景稀释边缘伪影。
2. **时序正确性**：比较预测变化和真实变化，`E_delta = mean(|Δs_pred - Δs_gt|)`。静止场景表现为抖动；运动场景会惩罚未跟上的历史残留。它是本项目定义的指标，不是论文的 TAE。
3. **运动响应与立体强度**：真实深度阶跃达到目标 90% 所需更新数、前景/背景对比度；防止用冻结、扁平化、长时间平均来换低时序误差。
4. **最终合成画面**：后续用独立几何场景生成左右眼真值，再测 RGB/LPIPS/tOF 或 ColorVideoVDP。必须覆盖遮挡露出、细线、低对比轮廓、横移、镜头推拉与切镜；单目缺失区域不存在可凭空恢复的真实纹理。
5. **真实片段代理量**：双向 DIS 一致性、亮度残差和边界有效性确定可信掩码，只在该掩码中测光流对齐的深度变化，另报覆盖率。该量同时包含真实深度运动、光流错误、推理错误；下降不能单独证明改善，上升也是要调查的信号。

最终眼镜验收还需同片段、同强度、随机 A/B 顺序的人眼评价，分别记录拖影、轮廓抖动、立体感和不适感。固定分辨率、深度更新率与播放时间窗，不能混用诊断里的丢帧数来代替画质分数。

## 与 DLSS / FSR 的关系

[此前调研](2026-09-12-dlss-fsr-sbs.md)表明时序重建依赖正确运动信息、历史重投影、遮挡判断与历史置信度。本轮只借鉴“历史不是全收或全丢”的思想，测试连续置信度；没有移植 DLSS 网络、FSR 4 内部模型或运动矢量系统。

当前 RGB L1 差异只是外观变化代理，归一化深度差也不是运动真值。颜色相同的前后景、大范围尺度漂移、低分辨率轮廓混合、旧深度配新颜色，依然会出错。此轮稳定器实验不能解决整个管线的时间配对和填洞问题。
