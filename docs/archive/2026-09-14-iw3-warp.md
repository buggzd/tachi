# iw3 立体生成源码阅读与弹性网格实验

只读源码，未安装、运行 iw3 或下载模型权重。阅读版本：
`nagadomi/nunif` commit `d23721f1b5f0a4c92c3ee1be013180bf298730c5`。

## 实际调用路径

- [utils.py](https://github.com/nagadomi/nunif/blob/d23721f1b5f0a4c92c3ee1be013180bf298730c5/iw3/utils.py#L1960)
  CLI 默认 method 为 `row_flow`。
- [stereo_model_factory.py](https://github.com/nagadomi/nunif/blob/d23721f1b5f0a4c92c3ee1be013180bf298730c5/iw3/stereo_model_factory.py#L112)
  把该别名解析为 RowFlowV3，加载独立权重，使用 delta 输出模式。
- [backward_warp.py](https://github.com/nagadomi/nunif/blob/d23721f1b5f0a4c92c3ee1be013180bf298730c5/iw3/backward_warp.py#L193)
  将深度、强度与会聚特征输入模型，得到横向采样偏移。模型可以在低于原视频的
  尺寸运行，再把采样网格插值到原图尺寸。可分步 warp，另一只眼可通过翻转处理。
- [row_flow_v3.py](https://github.com/nagadomi/nunif/blob/d23721f1b5f0a4c92c3ee1be013180bf298730c5/iw3/models/row_flow_v3.py#L32)
  用卷积与 WABlock 预测一个横向 delta，纵向偏移置零。核心不是 RGB 生成器，
  默认 delta 路径不把 RGB 送进偏移预测器。
- 最终由 `grid_sample` 双线性反向采样颜色。普通设备越界用 border，MPS 路径
  使用 reflection。每个目标像素都能取得源图颜色，但这不代表恢复了遮挡背景，
  仍可能拉伸、重复或采错纹理，也没有据此证明网格坐标单调。

`grid_sample` 这里表示密集采样坐标场，不等于图形 API 的三角网格。
RowFlowV3 名称里的 flow 也不是前后视频帧光流。

项目还提供多个独立路线：简单 `backward`、深度排序 `forward_fill`、
带图像修补的 `forward_inpaint`，以及 MLBW 多层反向 warp。
[mlbw.py](https://github.com/nagadomi/nunif/blob/d23721f1b5f0a4c92c3ee1be013180bf298730c5/iw3/models/mlbw.py#L105)
预测各层横向偏移和 softmax 权重，对多次采样结果加权；部分型号还输出洞掩膜。
不能把这些可选方案统称为默认方案。

[README 方法表](https://github.com/nagadomi/nunif/blob/d23721f1b5f0a4c92c3ee1be013180bf298730c5/iw3/README.md#stereo-generation-method-left-right-image-generation)
说明 RowFlowV3 以 forward_fill 合成立体结果训练，简单 backward 方法有较多鬼影。
因此“每个像素都有颜色”不等于画质正确，学习出来的采样场是重要区别。

## 对 tachi 的参考价值

优先验证无补洞的连续变形是否优于错误背景填充。若成立，再比较解析构造与
学习型反向位移预测。后者可考虑低分辨率运行、全分辨率采样，但模型算力、
输出稳定性、许可与端侧支持均需单独验证，本轮不声称可直接部署。

本轮 tachi 的 `elastic` 是独立解析算法，未移植 iw3 模型：每行格子宽度限制
为正并归一化到屏幕边界，用拉伸/压缩保证网格全覆盖。该约束甚至会改变实际
会聚位置，与原透视网格、原像素公式和 iw3 默认路线都不等价。
实验继续使用现有 2%／98% 深度和半帧率/两帧延迟，不新增时间滤波。
算法与验证入口见 [StereoLab](../../StereoLab/README.md)。
