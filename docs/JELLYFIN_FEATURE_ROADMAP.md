# 功能范围与后续路线图

## P1：大型媒体库与输入体验

- 首页和媒体库改为服务端分页，替代固定上限读取；保留完整列表、排序与焦点恢复。
- 增加类型、年份、评分和演职人员筛选，以及从演职人员/系列继续浏览。
- 为超长标题、空媒体库、缺失图片和大规模文件夹补齐真机回归样本。

## P2：剧集与播放队列

- 补齐缺失集提示、特别篇和跨季导航。
- 自动播放下一集、随机播放、播放队列和队列编辑。
- 加强正常结束、手动停止、异常中断与跨设备续播的一致性。

## P3：高级播放增强

- 播放前选择媒体版本与画质上限，完善超多轨道菜单。
- 字幕延迟调节、章节、缩略图进度条和跳过片头能力。
- 在已有视频信息面板上补充可操作的转码失败诊断，不暴露任意服务端错误。

## P4：账户与设备体验

- 完善失效账号的重新认证提示与连接诊断。
- 手机端增加队列管理和完整播放控制。
- 扩充 RayNeo 焦点、长按、返回键、实际插拔、USB 失败和双显示生命周期回归。

## 性能验证与研究

- 原生播放已接入正式产品，并提供可导出的原生/QNN 技术报告；本轮已测 2D HEVC/MKV/ASS、外接 H.264/SBS/QNN，尚待音轨、HLS、位图字幕、后台与完整模式切换矩阵的实机回传，以及长时热态、精确同步和画质验收，见 [原生播放](NATIVE_VIDEO.md)。
- GPU 稳定、GPU 输入预处理、固定主机输出和双捕获有界流水线已接入实验开关，见 [输入与流水线实测](performance/2026-09-13-gpu-input-pipeline/README.md)。完整 518 图的注册共享输入/输出已在独立 benchmark 经 3 张图、100 次 GPU→HTP→GPU 检查通过；产品仍使用主机缓冲。后续接入实际预处理/稳定器和异步同步机制、分离离屏计算与呈现、处理实测 PTS 长尾，并补充非充电长时预算；光流重投影与动画特化模型仍属研究，正式路径不能称为零拷贝。
- 对同一视频开展 10–20 分钟热态与非充电功耗测量，追踪 4K60 剩余丢帧；短时静态 SBS 优化已经完成，不再重复列为待开发。
- 保留 Liquid 可见效果，继续测量合成区域与缓存；现有报告没有证明其首页主要开销已解决。
- 评估不兼容 MKV 的无损重封装、超大库按需挂载、长字幕和长片 HLS 内存压力。先取得证据，再调整兼容声明、缓冲或渲染策略。

离线下载、播放列表编辑、世界固定/头部追踪目前不属于已实现能力，也不因历史 Jellyfin Web 调研出现过而自动进入近期计划。

功能完成后更新本页及对应维护文档；验证要求见 [开发指南](DEVELOPMENT.md#验证)。样本不得包含局域网地址、令牌或真实凭据。

## 实时 3D 后续顺序

1. 按[主路线](SBS_TECHNICAL_ROUTES.md)固定 392 同帧 GPU 局部液化及用户参数，完成上列工程验收，再将 liquid 配置纳入正式 Full 发布；本次文档更新不改变现有发布默认值。
2. 已完成[轮询调度三轮短测](performance/2026-09-15-gpu-poll-short/README.md)，独立线程暂不默认启用；[捕获与液化顺序优化](performance/2026-09-15-capture-order/README.md)已进入 liquid 实验包（短测 23.62 Hz，未保证 24 Hz）；[两轮融合与终点采样复用](performance/2026-09-16-liquid-shaders/README.md)已完成等价和完整 tachi 短测，暂不默认启用；下一步分析最终重建搜索的 GPU 瓶颈并排查冷启动 UI 裁切，后续对照每轮 3 分钟，长时间观影由用户反馈；继续接入完整模型注册共享缓冲，保持同帧配对与有界生命周期，测量真实帧龄、等待、呈现与热态收益。
3. 原像素偏移、旧双档和网页候选保留回归；暂停无明确收益证据的算法扩展。
