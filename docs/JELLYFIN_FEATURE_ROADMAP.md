# 功能范围与后续路线图

截至 2026-09-12，tachi 已实现下表中的原生客户端能力。眼镜负责浏览与播放，手机负责连接、账号和复杂输入。源码已实现与真机完整验收是不同状态；历史研究不再作为重复开发清单。

## 待复核问题

以下问题仍需独立复测或设备验收：

| 问题 | 已知证据与下一步 |
| --- | --- |
| MyGO 第三集无法播放 | 新报告记录到直放约 0.36 秒报 Media3 2000、随后 HLS 命令被拒绝；实际片源复现大小写路径校验缺陷并修复。重复原生字幕解析已关闭，直放原始异常原因及手机回退播放仍待复测，见 [回传分析](performance/2026-09-12-user-diagnostics/mygo-followup.md) |
| SBS 鬼影与深度抖动 | 已建立[离线量化与候选消融](performance/2026-09-12-artifact-evaluation/README.md)，采用连续外观置信度；浅轮廓/亮度扰动改善，但低对比快移压力场景仍退化，新增[匿名评分页与 392 模型测试包](performance/2026-09-12-quality-trials/README.md)，[实机分辨率扫描](performance/2026-09-13-resolution-sweep/README.md)已验证 392/518/644 的共享 lab QNN + SBS，770 在会话创建时内存失败；正式播放器画质、外接眼镜与长时热态仍待 A/B。另有默认关闭的[GPU 深度稳定实验](performance/2026-09-13-gpu-stabilization/README.md)，保留分位数/滤波公式并使用配对颜色快照，已完成数值检查和共享管线对照；不替代时序/遮挡画质优化。12 Hz 深度仍叠加最新颜色、缺少运动重投影和显式遮挡处理；继续按 [公开时序重建研究](archive/2026-09-12-dlss-fsr-sbs.md) 验证 PTS 对齐、置信度历史融合与保边上采样，不能用丢帧 0 代表画质通过 |
| ASS 字幕的设备验收 | 已改为原始 ASS 本地渲染并关闭对应视频流的字幕选择；桌面验证了实际测试集、样式/动画/卡拉 OK/绘图与字体回退。仍需在 Android APK 上验收 file 资源加载、视频同步、续播/切轨及 2D/SBS 显示，桌面验证不替代真机播放 |
| renderer 崩溃后的停止上报 | [清理记录](performance/2026-09-07/README.md#构建清理及后续建议) 曾需补发停止上报清理服务端状态。恢复首页不代表服务端播放/转码会话已结束；需复测并补齐异常停止路径 |
| 中英文设备验收 | 桌面已检查手机登录/设置切换和眼镜设置/教学排版，构建及自动测试通过；系统语言变化、双端冷启动/恢复、播放中 2D/SBS 切换仍按设备矩阵验收 |
| 后续 UI 的设备验收 | 壁纸编辑、文字自适应、玻璃透明度及本地时钟不能沿用早期 UI 的真机通过结论；按 [设备矩阵](ANDROID_ARCHITECTURE.md#device-regression-matrix) 验证，时钟另检查分钟更新、前后台恢复及两眼/播放器可读性 |

## P1：大型媒体库与输入体验

- 首页和媒体库改为服务端分页，替代固定上限读取；保留完整列表、排序与焦点恢复。
- 增加类型、年份、评分和演职人员筛选，以及从演职人员/系列继续浏览。
- 为超长标题、空媒体库、缺失图片和大规模文件夹补齐真机回归样本。

## P2：剧集与播放队列

- 补齐缺失集提示、特别篇和跨季导航。
- 自动播放下一集、随机播放、播放队列和队列编辑。
- 加强正常结束、手动停止、异常中断与跨设备续播的一致性。

## P3：高级播放增强

- 播放前选择媒体版本与画质上限，完善超多轨道菜单。
- 字幕延迟调节、章节、缩略图进度条和跳过片头能力。
- 在已有视频信息面板上补充可操作的转码失败诊断，不暴露任意服务端错误。

## P4：账户与设备体验

- 完善失效账号的重新认证提示与连接诊断。
- 手机端增加队列管理和完整播放控制。
- 扩充 RayNeo 焦点、长按、返回键、实际插拔、USB 失败和双显示生命周期回归。

## 性能验证与研究

- 原生播放已接入正式产品，并提供可导出的原生/QNN 技术报告；本轮已测 2D HEVC/MKV/ASS、外接 H.264/SBS/QNN，尚待音轨、HLS、位图字幕、后台与完整模式切换矩阵的实机回传，以及长时热态、精确同步和画质验收，见 [原生播放](NATIVE_VIDEO.md)。
- GPU 稳定、GPU 输入预处理、固定主机输出和双捕获有界流水线已接入实验开关，见 [输入与流水线实测](performance/2026-09-13-gpu-input-pipeline/README.md)。后续优先验证实际深度图的 GPU/NPU 共享缓冲、离屏计算与呈现线程分离、媒体 PTS 对齐和长时预算；光流重投影与动画特化模型仍属研究，正式路径不能称为零拷贝。
- 对同一视频开展 10–20 分钟热态与非充电功耗测量，追踪 4K60 剩余丢帧；短时静态 SBS 优化已经完成，不再重复列为待开发。
- 保留 Liquid 可见效果，继续测量合成区域与缓存；现有报告没有证明其首页主要开销已解决。
- 评估不兼容 MKV 的无损重封装、超大库按需挂载、长字幕和长片 HLS 内存压力。先取得证据，再调整兼容声明、缓冲或渲染策略。

离线下载、播放列表编辑、世界固定/头部追踪目前不属于已实现能力，也不因历史 Jellyfin Web 调研出现过而自动进入近期计划。

功能完成后更新本页及对应维护文档；验证要求见 [开发指南](DEVELOPMENT.md#验证)。样本不得包含局域网地址、令牌或真实凭据。
