# tachi v0.5.0 — Jellyfin 认证兼容与手柄导航

升级 Jellyfin 后，旧版 tachi 可能完成登录却无法加载媒体库、封面或视频。v0.5.0 统一使用标准认证格式，修复这类连接失败，并包含自 v0.4.1 以来的手柄导航与详情焦点改进。

## 更新内容

- Jellyfin API 使用标准 `Authorization: MediaBrowser`，封面、视频、HLS、字幕与字体请求使用 `ApiKey`，兼容禁用旧认证的服务器。密码登录、Quick Connect 和已保存会话沿用原有流程，无需开启服务端旧认证。
- 服务端返回的媒体地址在附加令牌前校验服务器来源和安装子路径，清理旧令牌参数。无效的备用 HLS 地址不会阻止原本可用的直放。
- 新增 Android 原生手柄导航：十字键、左摇杆、确认与返回，包含死区、按住连发、重复输入抑制和断连清理。手柄搜索不自动抢占手机键盘；不同型号、USB/蓝牙及双窗口完整设备矩阵仍待验收。
- 修复详情尚未加载完成时焦点过早落到返回按钮的问题；详情就绪后优先聚焦可播放目标，同时保留用户已经移动的焦点。

## 下载与升级

本次 GitHub Actions 构建并发布正式签名的 **Lite ARM64 APK** 及 SHA-256 校验文件。Lite 支持原生 2D 和平面 SBS，不包含深度模型或 QNN，不能进行实时 2D 转 3D。

版本为 `0.5.0` / `versionCode=11`，沿用原应用 ID 和正式签名，可覆盖升级并保留设置。已安装 Full 的用户请注意：覆盖安装 Lite 后，本版不提供实时 3D；需要该功能时应等待同版本 Full 附件，以 Release 实际附件为准。Full 需另行本地构建、签名和设备验收，不由本次 Actions 生成。实时 3D 目前仅在骁龙 8 Elite Gen 5（SM8850/V81）手机上测试过，不保证其他设备兼容。

## 验证范围

认证修复已在 Jellyfin 12.4.0 上对比验证：旧认证返回 401，标准认证正常读取媒体库；修复后的客户端源码可加载媒体库、封面、HLS 和字幕。前端、联调服务、JVM 与构建检查覆盖认证格式、Quick Connect、媒体地址边界及无效备用地址下的直放行为。

手机系统拒绝了本轮 ADB 测试包安装，因此上述接口与自动化结果不代表已完成新版 APK 的真机登录、会话恢复、播放或手柄设备矩阵验收。
