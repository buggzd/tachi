# tachi v0.4.0

这一次，我们把一个有些疯狂的想法做进了 tachi：**让手机在播放普通 2D 视频时，实时估计画面深度、生成左右眼画面，再通过眼镜看到有立体层次的内容。** 不用先把整部影片离线转换成 3D 文件。

从上一版 v0.3.1 到现在，tachi 不只是多了一个开关。我们重做了 Android 播放核心，走过桌面实验、手机 NPU 验证、不同深度与合成方案的对照，最终把实时 2D → SBS 3D 接进了真正的 Jellyfin 播放流程。与此同时，字幕、续播、遥控、浏览和界面语言也有了一轮完整更新。

> **设备兼容性提醒：目前仅在搭载骁龙 8 Elite Gen 5（8E Gen 5，SM8850 / V81）的手机上测试过实时 3D。其他芯片、其他代际骁龙及其他手机尚未验证，不保证可用或具有相同表现。** 这不是面向所有 Android 手机的通用实时 3D 兼容承诺。

本日志覆盖 v0.3.1（`9e03fa66ad8c0b2b629e6a1e2ac7d24e1703829f`，2026-09-08）以来的工作，而非仅发布前几次提交。版本为 `0.4.0`，Android `versionCode=9`。

## 核心突破：普通视频，实时变成立体画面

- **Full 新增实时 2D → SBS 3D。** 在 SBS 虚拟银幕模式下播放视频，开启播放器里的「实时 3D」，由手机本地的深度模型与 Qualcomm QNN / NPU 推理生成深度，再由 GPU 合成左右眼画面。不需要预先制作双目片源，也不把画面上传到云端做深度转换；视频本身仍按原来的方式从 Jellyfin 播放。
- **不只是把同一张画面放到两只眼睛前。** 原有平面 SBS 是把 2D 内容放进虚拟银幕；实时 3D 则根据估计的场景深度产生左右眼视差，让画面中的前景与背景具有不同的立体层次。
- **深度与视频严格对应同一帧。** 处理完成后一起提交匹配的视频和深度；来不及时重复上一组有效画面，不把上一帧的深度硬套到新的运动画面上，减少由时序错配带来的轮廓问题。
- **采用 GPU 背景局部液化方案。** 在前景边缘拉伸邻近背景纹理，处理视差变换后露出的区域。它不是生成式补全，不能恢复原画面中被遮挡的真实内容；复杂遮挡、细线、快速运动仍可能出现拉伸、形变或深度判断误差。
- **字幕与控件保持独立。** 本地渲染的字幕和播放控件不参与视频液化，实时 3D 与本地字幕可以同时开启；如果文字已经烧进原视频，它仍会随视频一起处理。

Full 正式采用我们测试过的 **392×224 深度模型与完整 liquid 配置**：24 Hz 采样目标、双捕获槽、GPU 预处理和深度处理、异步捕获、成对画面缓存，以及先捕获后提交液化。固定效果参数为强度 0.85、羽化 96 px（每眼源宽基准）和拉伸 65%。392×224 是深度图分辨率，不是把最终观看的视频降到这个尺寸。

这条路线经历了像素位移与补洞、深度网格、连续形变、背景修复和时间处理等方案的研究与对照，也做了不同推理尺寸、GPU 输入处理、双槽流水线和捕获调度的真机验证。最终选择以同帧配对和观看效果为核心的方案；没有明确端到端收益的独立轮询线程、融合轮次与采样复用仍保持关闭。完整模型共享缓冲目前只有独立实验验证，**正式产品不能称为零拷贝**。

### 已经做到什么，还不能承诺什么

在已测试设备与 RayNeo Air 3s 上，实际 Jellyfin HEVC / WebVTT 播放完成了约 **21 分 25 秒连续有效实时 3D**，平均新配对画面更新率 **22.54 Hz**。这不是把独立演示程序或模型准备时间算进播放时长。

但该测试在充电环境下完成，只代表对应设备、片源和配置：**24 Hz 是目标，不是稳定帧率保证，更不是 60 fps 的实时转换承诺。** 仍需更多非充电长时间使用、其他编码和字幕、音画同步、显示恢复与插拔测试。严格同帧不等于零延迟；音频没有额外固定延迟补偿。自动估计的立体效果也不等同于原生双目拍摄。

技术路线、原始证据与未验收项见 [实时 SBS](https://github.com/buggzd/tachi/blob/main/docs/REALTIME_SBS.md) 和 [实际播放长测](https://github.com/buggzd/tachi/blob/main/docs/performance/2026-09-15-native-liquid-product/README.md)。

## 播放核心：从 WebView 视频迁移到原生 Media3

- Android 视频现在由 **Media3 / MediaCodec / GLES** 播放；WebView 负责目录、控件与字幕，不再承担 Android 主视频解码。2D、平面 SBS 和实时深度 SBS 共用一个原生播放器，保持单路音频与进度上报。
- 根据原生容器与设备解码能力选择直放，支持范围内的 MP4、WebM、MKV；不兼容内容通过 Jellyfin 的 H.264 / AAC HLS 回退。当前输出为 SDR，已知 HDR 内容请求服务端转码，不宣称 HDR 透传。
- 修复 Jellyfin HLS 路径大小写导致有效播放请求被拒绝的问题，避免原生层重复解析由前端处理的字幕。
- 视频信息面板可查看实际原生解码器、输出格式、缓冲和解码计数，不再仅依靠 WebView 能提供的信息判断播放状态。
- 增加独立保留的播放准备、回退与失败记录，并补充深度和配对耗时诊断；后续成功播放不会立即覆盖先前的失败证据。分享报告继续排除服务器地址、令牌、账号、片名和字幕原文。

## 字幕：本地保留 ASS / SSA 的表现力

- 新增基于 **libass** 的 ASS / SSA 本地渲染，保留字幕样式、位置、动画、卡拉 OK、字体及矢量裁剪，不再把复杂 ASS 当作普通文字字幕处理。
- 优先使用媒体附带字体，内置思源黑体作为字体缺失时的回退，不依赖在线字体服务。
- 普通文字字幕继续使用 WebVTT，位图字幕仍由服务器烧录；切轨、暂停、seek 与退出时同步清理和更新字幕状态。
- 本地字幕渲染失败会明确报错，不会静默改成无样式文字或自动请求烧录。不同片源、复杂特效及 2D / SBS 下的完整同步体验仍需持续真机验证。

## 续播与遥控：更容易找到进度，也更容易控制

- 退出播放后刷新详情与观看进度；剧集主播放按钮显示续播进度和具体时间，重新进入时定位最近观看的季与集，并标出「看到这」。
- 改善选集的已看标记：已看状态更醒目，重看时保留已看标识，与最近观看位置区分显示。
- 进度条聚焦时，短滑保留十秒步进；较长的**横向拖动先预览目标进度，松手才提交一次跳转**。支持拖动反向、边界限制、取消及暂停状态保持，手机完整进度条也可定位。
- 这期间曾试验圆环加速快进；最终发行采用横向预览方案，不把两种历史交互同时列为当前功能。
- 遥控器隐藏系统栏，减少操作时的界面干扰；修复不可播放条目或禁用按钮导致默认焦点失效的问题。

## 媒体库与界面：补齐日常使用中的细节

- **新增简体中文 / English 双语界面**：默认跟随系统，可在手机连接页及两端设置中切换，保存并同步。语言切换不修改服务器媒体标题或字幕内容；另提供英文 README。
- 修复合集组、合集、子合集逐级浏览与返回路径，修正虚拟合集视图的查询方式，避免进入后显示错误层级。
- 封面比例判断对齐 Jellyfin Web，改进合集、文件夹与缺失元数据条目的统一布局；限制分集长文件名和标题对卡片宽度的影响。
- 修复从相关推荐打开新详情时沿用旧滚动位置的问题。
- 修复眼镜外接 WebView 不持有窗口焦点时，**liquid-glass 模糊背景不随遥控封面变化**的问题；Mirror 2D 与 SBS 首页已有真机验证，详情选集的 SBS 全量回归仍待补齐。
- 浏览页与播放器控件新增紧凑的本地时间显示，并调整字号，避免抢占主要内容。
- 恢复手机端自定义服务器连接页面。

## 眼镜连接：减少重复确认的打断

为 Air 3s 增加 USB 默认处理应用声明，使系统可复用用户选择的授权；保存 SBS 偏好时，尽可能在系统镜像确认前完成硬件模式准备，减少先进入 2D、再切换 SBS 带来的重复连接过程。

USB 授权和 HyperOS 的屏幕镜像确认仍属于两套系统机制。应用不能绕过系统确认，也不能保证所有机型、插拔或模式切换都不再弹窗；系统关闭外接显示时，仍需手动开启屏幕镜像。

## 下载哪一个版本？

| 版本 | 提供的能力 | 如何选择 |
| --- | --- | --- |
| Lite | 原生 2D 播放、平面 SBS，不包含深度模型、ORT 或 QNN | 不需要实时 3D 时选择；没有在线下载模型的入口 |
| Full | Lite 的播放能力，以及本地实时 2D → SBS 3D | 想体验实时 3D 时选择；目前仅在骁龙 8 Elite Gen 5 手机上测试过 |

正式附件分别命名为 `tachi-0.4.0-lite-arm64-v8a.apk` 与 `tachi-0.4.0-full-arm64-v8a.apk`，附带 `.sha256` 校验文件。Lite 由 GitHub Actions 构建；Full 由维护者在相同发布源码上本地构建、正式签名并验收后补充，**请以 Release 实际附件为准**。

两版保持相同应用 ID、版本和长期正式证书，可以覆盖升级或相互切换并保留设置，不能并排安装。支持从 v0.3.1 升级到 v0.4.0；无需为本次更新卸载旧正式版。Debug 包不是正式升级包。

开发与发行侧同时完成了前端 bundle 自动生成、不再提交构建产物、APK 内前端字节一致性校验，以及模型和运行库的固定哈希校验；修复 Full 切回 Lite 时 APK 仍可能残留旧 ZIP 数据的问题。历史实验和性能证据保留，现行说明与归档文档分开维护。发布操作见 [发布手册](https://github.com/buggzd/tachi/blob/main/docs/RELEASE.md)。
