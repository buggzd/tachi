# tachi v0.4.0

版本 `0.4.0`，Android `versionCode=9`。保持应用 ID、持久化标识与正式签名身份，支持同签名覆盖升级。

## 本版变化

- Full 默认采用已测试的 392×224 严格同帧 GPU liquid 完整配置，而非只替换模型：24 Hz 调度目标、两个捕获槽、GPU 预处理/深度处理、固定输出、异步捕获和先捕获后液化；强度 0.85、羽化 96 px、拉伸 65%。
- 独立轮询线程、融合轮次与采样复用继续关闭；正式配置不启用 daily 实验夹具和试验日志。Lite 继续提供原生 2D 与平面 SBS，不带模型/QNN/ORT。
- 保存 SBS 偏好时，尽可能在系统镜像授权前完成硬件模式准备；USB 默认处理授权可复用。HyperOS 的系统镜像确认仍由系统管理，不能承诺所有机型均无需再次确认。
- 修复外接 WebView 缺少原生焦点事件时，liquid-glass 背景不跟随遥控封面的问题。
- 播放进度采用横向拖动预览、松手单次提交；打开相关条目详情时重置滚动位置。
- 同步现行构建、版本与第三方说明；保留历史研究及原始测量数据。

## 发行与边界

Lite 由 GitHub Actions 构建，Full 由维护者在同一提交上本地构建、正式签名并验收后补充。两版同版本、应用 ID 与签名，可覆盖切换；不得发布 unsigned 或 Debug 签名包。操作见 [发布手册](../RELEASE.md)。

Full 当前只验证 SM8850/V81。24 Hz 是采样目标，不是稳定帧率承诺；既有 HEVC/VTT 充电长测平均 22.54 Hz，不能代替其他片源、非充电热态、音画同步和完整生命周期验收。详见 [实时 SBS](../REALTIME_SBS.md)。
