# tachi v0.4.1 — 修复正式版实时 3D 闪退

v0.4.0 Full 存在开启实时 3D 即闪退的问题，已撤回为草稿；修复版完成正式包设备验收前，最新公开版本仍为 v0.3.1。此次使用新版本 `0.4.1` / `versionCode=10`，不替换旧标签或同名附件。

## 修复内容

- 修复 Release 混淆裁剪误删 ONNX Runtime JNI 构造方法，导致模型输出信息查询触发 native abort。保留完整 JNI 接口，并在 Full 出包时检查 R8 结果，防止再次出现只在正式包闪退的问题。
- 补齐跨重启的本地崩溃报告：保留最近一次 Java 异常的有限符号栈、时间和版本；Android 11+ 同时读取本应用的系统进程退出记录，区分 native crash、ANR、内存终止等。
- Android 12+ 在系统仍保留 native tombstone 时，仅提取固定的 ORT/JNI 失败特征。不导出原始 tombstone、任意异常消息、服务器地址、账号、媒体标题或凭据，不自动上传。
- 系统可能清理历史记录，旧 Android 无法提供同等 native 证据；报告明确标注证据缺失。闪退后重新打开应用，从手机设置分享诊断即可查看已有历史。

## 相较 v0.3.1 的主要更新

我们把普通 2D 视频在手机上实时转换为有画面深度的 SBS 3D：本地 QNN/NPU 估计深度，GPU 生成左右眼视差，无需预先离线转换整部影片。Full 使用经过测试的 392×224 严格同帧 liquid 完整配置，而不是平面 SBS 的双眼复制。

这期间还完成了 Android 原生 Media3 播放核心迁移、ASS/SSA 本地样式字幕、中英文双端界面、剧集续播与已看标记、横向拖动进度预览、合集层级浏览、封面布局与背景焦点修复，以及减少 SBS 连接重复确认。完整开发周期说明见 [v0.3.1 以来的功能总结](https://github.com/buggzd/tachi/blob/main/docs/releases/v0.4.0.md)。

**实时 3D 目前仅在骁龙 8 Elite Gen 5（SM8850/V81）手机上测试过，不保证其他芯片或手机兼容。** 24 Hz 是采样目标，不是稳定帧率保证；单目深度估计与背景拉伸不等于原生双目拍摄，复杂运动和遮挡仍可能形变，并存在处理延迟。

Lite 提供原生 2D 和平面 SBS，不含模型/QNN；Full 增加实时深度转换。两版同应用 ID、长期正式证书和版本，可覆盖升级并保留设置；已安装 0.4.0 的用户无需卸载。以公开 Release 实际附件为准。

## 发布门槛与当前验证

2026-09-17：两套前端检查、JVM、lint 与构建通过；当前 Full 应用 150 项、播放器 26 项 JVM 测试以及 18 项脚本测试通过，包含诊断脱敏/限额和 JNI 保留检查。正式证书验证通过。

尚未完成正式包实际 SBS 播放、3D 开关与重启后报告导出的设备验收。独立 JNI 探针已编译，但安装被设备系统拒绝，不能记为通过；当前无外接眼镜显示。以上门槛完成前不推送发布标签、不公开修复版。
