# tachi（塔奇） 使用指南

这份文档面向安装和使用应用的人。源码环境、构建参数、签名和测试命令见 [开发和构建指南](DEVELOPMENT.md)。

## 界面语言

支持简体中文和 English，默认跟随系统（中文系统使用简体中文，其他语言使用英语）。登录前可在手机连接页右上角选择语言；登录后可在手机「设置 → 外观与交互 → 语言」或眼镜设置中修改，两端自动保存并同步，无需重新登录。退出账号保留选择，「恢复默认偏好」恢复跟随系统。

语言设置只改变应用界面，不翻译服务器上的媒体名称、简介或字幕，也不会改变正在播放的视频。开发与词条维护见 [i18n 说明](I18N.md)。

## 使用前准备

你需要：

- RayNeo Air 系列眼镜及其配套 Android 手机；
- 一台已经配置好媒体库和用户的 Jellyfin 服务器；
- 手机能够访问 Jellyfin 服务器，自动发现时两者应位于同一局域网；
- 从 [GitHub Releases](https://github.com/buggzd/tachi/releases) 下载的正式签名 APK，或自行构建的 APK。

应用只构建 ARM64 版本，并依赖手机上的 Android System WebView。

## 安装

正式版本可从 GitHub Releases 下载，并使用同页 `.sha256` 文件核对完整性。完成 Debug 构建后，APK 位于：

```text
AndroidApp/app/build/outputs/apk/debug/app-debug.apk
```

### 通过手机文件管理器安装

1. 把 APK 复制或发送到配套手机。
2. 在文件管理器中打开 APK。
3. 按 Android 提示允许当前文件来源安装未知应用，然后完成安装。

Debug 包使用 `.debug` application ID 后缀，可以和正式包同时安装。

### 通过 ADB 安装

```bash
adb install -r AndroidApp/app/build/outputs/apk/debug/app-debug.apk
adb shell am start \
  -n com.jellyfinforrayneo.client.debug/com.jellyfinforrayneo.client.MainActivity
```

如果系统返回 `INSTALL_FAILED_USER_RESTRICTED`，请在手机开发者选项中允许当前 ADB/USB 安装请求后重试。不要通过脚本绕过系统安全设置。

## 首次连接

1. 将 RayNeo Air 接到配套手机并启动应用。
2. 在手机上从发现结果中选择 Jellyfin 服务器，或手动填写服务器地址。
3. 推荐使用 Quick Connect；也可以输入用户名和密码登录。
4. 登录成功后，眼镜端会自动加载媒体库；第一次使用时会先显示遥控入门教学。
5. 在手机上进入触控板：滑动移动焦点，单击确认，双击返回。

眼镜由手机供电，因此眼镜端不会显示“等待手机连接”页面。手机首页会分别显示会话、眼镜画面和媒体库是否已准备就绪。

## 互动遥控教学

拿好手机、打开触控板，然后把目光留在眼镜画面上。单击开始练习，跟随拇指动画依次完成向右、向下、向左、向上滑动，再单击打开练习卡片、快速双击返回。每一步都需要实际操作，完成后会点亮底部进度；滑错时会提示当前需要的动作。

欢迎页可选择「稍后再学」，也可双击跳过。练习中双击会暂停并显示继续/退出选项；最后的双击练习会执行返回动作。教学不播放真实影片，也不会改动观看记录。完成或跳过后不会在下次启动时重复弹出，随时可从眼镜端侧栏「遥控教学」重新练习。

## 填写服务器地址

局域网自动发现使用 Jellyfin 的 IPv4 UDP 广播。发现不到服务器时，可以手动填写完整的 HTTP 或 HTTPS 地址，例如：

```text
http://jellyfin.example.test:8096
https://media.example.test/jellyfin
http://[2001:db8::20]:8096
```

应用支持 IPv4、具有 A/AAAA 记录的域名、带方括号的 IPv6 字面量，以及安装在子路径中的 Jellyfin。

使用 IPv6 时请注意：

- 带端口的 IPv6 必须写成 `http://[address]:port`；
- 不带端口的裸 IPv6 会自动补方括号；
- 带 `%wlan0` 一类 zone identifier 的链路本地地址无法在 Android WebView 中可靠复用，会被拒绝；
- 对 IPv6-only 服务器，请使用域名、全局 IPv6 或 ULA 地址手动连接。

公网连接应使用证书受信任的 HTTPS。应用允许明文 HTTP，是为了兼容局域网中的 Jellyfin 服务器。

## 登录与会话

- Quick Connect 是推荐登录方式，授权操作在 Jellyfin Web 中完成。
- 密码只用于本次认证请求，不会持久化。
- 选择记住登录后，会话保存在 Android 应用私有存储中，冷启动可以恢复。
- 点击设置页顶部的「服务器与账号」卡片会打开服务器与账号列表，进入页面不会退出当前连接。
- 每台服务器可以添加多个账号；点击账号行即可复用登录状态并切换眼镜媒体库。最多同时保留 12 个账号。
- 「添加服务器」用于发现或手动填写新地址；服务器卡片上的「添加账号」用于登录该服务器下的其他账号。登录失败或返回取消时，原连接保持不变。
- 已保存的账号与当前选择会在冷启动后恢复；未勾选保存的账号仅在本次运行中可切换。
- 点击账号旁的移除按钮并确认后，会删除本机对应的登录状态。移除当前账号会断开两端连接，其他账号继续保留。Jellyfin 返回未授权状态时，也只清除失效的当前账号。

## 界面风格

打开手机「设置 → 界面外观」，选择液态玻璃或 **simpleUI**：

- **液态玻璃（liquid-glass）**：默认外观，保留通透光影与流动质感。
- **simpleUI**：暖白手机展厅与深色眼镜界面，使用实色面板、细线焦点和轻量动效，减少装饰效果开销。

选择自动保存并同步到眼镜；重新连接、重启或退出账号后仍会保留。播放时也可以切换，
无需重新打开影片。「恢复默认偏好」会恢复液态玻璃。两种风格均保留黑色触控板。
在液态玻璃主题下，展开「界面外观」后可在「手机背景」中选择或更换图片。
「玻璃透明度」可统一调整设备、设置、账号管理卡片及底部导航，范围 0–100%，
默认 88%。数值越高越通透，文字与图标保持清晰，中央触控键保持实心。
滑动后自动保存，无需先选背景；恢复默认背景保留此值，恢复默认偏好重置为 88%。
支持 20 MB 以内的 JPG、PNG 和 WebP，图片仅保存在本机。取消或导入失败会保留原背景；
「恢复默认背景」可回到冰蓝背景。背景只用于 Liquid 手机页面，触控板和 simpleUI
不使用这张图片；切回 Liquid 会重新显示已选图片。恢复默认偏好也会重置自定义背景。

选图后点击「调整背景」：

- **文字配色**：默认「自动」，根据文字下方的背景、裁切和透明度选择明暗；
  也可固定为「浅色」或「深色」。设置玻璃卡片内的文字同样适配，调整玻璃透明度后
  会重新匹配；明暗混合的图片会辅以细描边。
- **裁切比例**：屏幕、9:16、3:4、1:1 或原图；配合 1–3 倍缩放选择保留的范围。
- **裁切位置**：拖动图片，或用水平/垂直滑杆定位；键盘方向键也可调整。
- **背景透明度**：0% 图片完全可见，100% 图片完全透明；默认 65%。调整时自动
  切到「界面预览」，查看背景铺满手机屏幕后与玻璃卡片搭配的效果。

点击「应用背景」保存；取消或返回不会改动上次设置。导入图片会保留，可反复
调整裁切。更换图片会重新居中并保留透明度与文字配色，恢复默认背景则清除全部背景调整。
预览与实现说明见 [界面主题](UI_GUIDE.md)。

「设置 → 外观与交互 → 遥控器背景」可选择当前的纹理背景或适合 OLED 的纯黑。
纯黑会关闭背景纹理和触摸光晕，保留必要文字、控件、手势提示与震动；空白区域
输出 `#000000`。OLED 黑色像素可停止发光，可见控件和系统键盘仍会亮。
选择会保存在本机，两种主题均可使用；切换账号或重启不会清除。

设置页的「关于与帮助」提供实际安装版本与构建号、GitHub 项目地址、Issue 反馈和
使用指南。项目、反馈和指南在系统浏览器中打开，返回应用后继续当前连接。

## 眼镜交互音效

眼镜侧边栏的「设置 → UI 音效」可以开启或关闭操作提示音，默认开启，选择自动保存。
关闭后立即停止提示音，不影响影片声音；重新打开时会播放一声开启提示。
该开关仅在眼镜端提供，重启、重新连接眼镜或切换账号后保留选择。

## 眼镜显示模式


手机设置中可以选择：

- **Mirror 2D**：在眼镜外接显示上呈现完整的单幅 2D 画面；
- **虚拟银幕（Stereo Virtual Screen）**：给左右眼加入相反的水平偏移，让普通 2D 内容呈现在可调远近感的平面银幕上。

两种模式始终只使用一个眼镜界面、一个视频和一条音频。切换最多等待 8 秒；失败或超时后，应用会结束黑屏遮罩并请求安全 2D，不会自动重复切换。外接显示仍由系统启用时会恢复可见画面；系统禁用外接屏时，需要先恢复输出。

显示模式选择、当前启用状态和切换结果统一放在「设置 → 眼镜显示 → 画面输出」。设备页保留眼镜连接状态、触控板入口和当前媒体会话。选中虚拟银幕只表示保存了偏好；只有实际状态为已启用时，靠近程度和大小才会作用于眼镜。失败后可点击「重新启用」发起一次切换。

选择虚拟银幕后，在「设置 → 眼镜显示 → 画面输出」中调整：

- **靠近程度**：基准、轻微、适中、较近。默认轻微；基准没有额外视差，后续档位逐步增加会聚。
- **银幕大小**：80%–95%，默认 90%。它与靠近程度独立，调整时无需重启播放。画面四周会保留黑边，以容纳双眼偏移。
- **检查左右眼**：交替闭眼，左眼应只看到 L，右眼应只看到 R。固定大小，在基准与其他档位间切换：青色框随内容移动，白框保持基准位置。离开设置后检查图自动关闭。

首次佩戴建议先用「基准」检查左右眼，再从「轻微」逐档尝试；出现重影或不适时回到基准或镜像 2D。设置使用相对档位，不显示未经设备与个人校准的米数。它改变的是整块银幕的远近感，片中物体仍是普通 2D，银幕也仍随头部移动。

只有硬件确认切换且实际输出与眼镜界面符合完整 SBS 的左右眼比例时，虚拟银幕才会启用。输出不支持时，设置页会显示回退原因；诊断报告包含输出尺寸和刷新率，便于排查。

**独立运行：** 应用通过 Android USB 直接控制已核对接口的 Air 3s，不需要安装或启动雷鸟 XR 空间。第一次需要改变眼镜硬件模式时，Android 可能询问是否允许 tachi（塔奇）访问眼镜 USB；允许后即可切换。拒绝后保留当前输出，不会反复弹窗；再次选择模式可重新授权。其他 USB 型号或接口尚需验证。

**HyperOS 屏幕镜像：** 连接眼镜后，需要手动开启手机系统的「屏幕镜像」，系统才允许眼镜显示画面；真实 2D/SBS 切换重新识别眼镜后，也可能需要再次开启。这是手机系统对外接显示的控制。看到「系统尚未启用眼镜输出」时，请先开启系统镜像，再返回应用。这里的系统屏幕镜像开关与应用里的 Mirror 2D/SBS 模式是两件事。

应用不会为了恢复输出打开其他眼镜应用，也不会修改系统权限。若眼镜已经处于所选分辨率，应用会直接使用，避免再次触发重连。切换等待超过 8 秒后先恢复系统输出，再重新启用所选模式。

开发者可通过 `adb shell dumpsys display` 核对外接显示状态；本轮先前使用的 `adb shell cmd display enable-display <眼镜显示ID>` 只是测试辅助操作，日常使用应按上述系统镜像流程操作。

## 浏览与播放

打开手机遥控器后自动进入沉浸式全屏，隐藏系统时间、电量和底部导航栏，屏幕边缘由黑色底层覆盖；退出遥控器恢复系统栏。从系统边缘滑动可临时唤出系统栏，返回应用后重新全屏。

资源没有可播放文件或分集时，详情页显示「暂无可播放内容」；方向操作会跳过禁用的播放按钮，仍可访问返回、收藏、观看状态和相关推荐。

海报墙采用 Jellyfin Web 的自动封面比例规则：根据整组主封面的比例选择竖版、方形、横版或横幅，缺少图片元数据的条目跟随所在网格，不再根据文件夹／电影／合集类型强制横竖。此规则共用于媒体库、合集、收藏、搜索结果、首页自动封面栏及相关推荐；整组都没有有效比例时，与 Web 一样回退为方形。Web 中固定横向的媒体库快捷入口、继续观看、下一集和分集栏仍为横向。文件夹和合集的进入操作不变。

眼镜端支持媒体库首页、继续观看、下一集、最近添加、搜索、筛选、文件夹和剧集浏览。电影、剧集、季和单集详情可以显示元数据、播放能力及用户状态。

媒体库中的「合集组」先列出 Jellyfin 创建的各个合集，再进入具体合集查看电影、番剧或子合集。面包屑与遥控返回均逐级返回；打开电影或番剧详情后返回，会保留进入时的合集路径。

剧集中途退出后，详情会等待停止上报完成并刷新观看数据，hero 的续播入口同步到最近观看的那一集。播放按钮以内部填充显示进度，并标出已看到的分钟、秒数；首次下滑进入选集时自动定位最近观看集，卡片显示「看到这」。进入剧集时默认选择最近观看的季，手动选季和搜索指定集数仍优先生效。短时观看位置在当前账号的本次会话内保留，重启或换设备后的续播记录以 Jellyfin 服务端为准。

播放时可以使用手机触控板或方向键完成：

- 播放与暂停；
- 调整进度、快退和快进；
- 切换上一集或下一集；
- 选择音轨和字幕；
- 调整音量并返回详情。

播放页初始焦点位于进度条。播放／暂停按钮仅在聚焦时亮起，未聚焦时使用暗底；播放状态通过图标和状态文字表示。

将眼镜端焦点移到播放进度条后，手机触控板不额外显示文字提示，调整目标与操作反馈在眼镜端查看。短距离左右滑动后退／前进 10 秒；横向拖动超过约 72 个屏幕逻辑像素进入预览，以固定距离比例调整目标（每 2 个逻辑像素约 1 秒，不随速度加速）。停住手指即可读时间，直接反向拖动可修正位置。眼镜显示目标时间及调整幅度，松手才实际跳转一次；播放／暂停状态保持不变。大跨度定位可拖动手机播放卡片上的完整进度条，同样松手跳转。

单击仍播放／暂停，上下滑动仍导航。焦点离开进度条、打开选项、收起控制栏、切集、触摸取消、多指触摸或手机切入后台会取消预览；断连导致预览消息中断时，眼镜会在约 2 秒后取消，不补执行跳转。手机完整进度条仅在眼镜进度条聚焦时可用。

应用在普通 2D 与 SBS 下均使用原生 Media3 播放，优先尝试系统支持的直放格式；不兼容的媒体会请求 Jellyfin 生成 H.264/AAC HLS。ASS/SSA 字幕由眼镜端的 libass 本地渲染，保留它支持的样式、定位、动画、卡拉 OK 和绘图语法；优先使用媒体附带字体，缺失时回退到内置思源黑体。ASS 保留原有字号和排版，普通文字字幕使用 WebVTT 和应用的字幕字号。选用本地字幕时，视频转码请求明确关闭字幕烧录，字幕渲染失败也不会自动改为服务端嵌字。位图字幕通过服务端烧录。是否能顺利回退取决于 Jellyfin 服务器的转码配置和可用资源。

控制栏右侧「视频信息」按钮可开启或关闭右上角常驻面板。控制栏收起后仍可查看编码、分辨率、码率、帧率、缓冲和丢帧，以及原始媒体参数；切换剧集时保持开启，退出播放器后关闭。解码方式显示 Media3 本次实际使用的解码器；系统能力不表示所有片源均已验证。已知 HDR 片源通过服务端转为 SDR。

## 诊断与隐私

如果眼镜画面或媒体库没有就绪，手机首页会显示网络、HTTP、响应格式或未知错误对应的安全提示。你也可以打开“设置 → 关于与帮助 → 分享诊断日志”，通过 Android 分享面板发送报告。

诊断报告以 `.txt` 文件通过系统分享，可发送给开发者。退出播放器后仍能导出最近的原生播放样本；请在强制结束应用前导出。报告新增解码器、缓冲/丢帧、字幕状态、QNN 与 GPU 耗时、深度帧龄。

诊断报告只包含应用、Android、WebView 和设备版本，网络能力，眼镜与显示状态，以及固定类型的事件。它不会包含：

- 完整服务器地址或局域网地址；
- 用户名、媒体标题或 Quick Connect 代码；
- Token、密码、会话内容或服务器响应正文；
- 任意原始异常文本。

分享前仍建议快速检查报告内容，并只发送给你信任的接收方。

## 常见问题

| 现象 | 建议 |
| --- | --- |
| 自动发现没有结果 | 确认手机和服务器处于同一局域网，或直接手动填写完整地址。IPv6-only 服务器不会出现在 UDP 发现结果中。 |
| 已登录但眼镜没有媒体库 | 查看手机首页的“眼镜画面”和“媒体库”状态，确认 WebView 网络可访问服务器，然后使用重试入口或重新连接眼镜。 |
| 3D 模式没有生效 | 查看首页/设置的实际状态；已保存不等于已启用。点击重新应用；若提示系统未启用眼镜输出，先恢复外接显示，参见上方 Android 16 限制。 |
| 视频无法直放 | 确认 Android System WebView 已更新，并检查 Jellyfin 是否允许为该用户转码及服务器是否有可用转码资源。 |
| 字幕没有显示 | 尝试切换字幕轨；位图字幕需要服务端转码烧录，普通文字字幕需要 WebVTT；ASS/SSA 需要可提取的字幕原文与支持 WebAssembly/Worker 的 WebView。缺失字体使用内置思源黑体，渲染失败不会自动烧录。 |
| 安装时报用户限制 | 在手机开发者选项或安装确认界面中允许当前来源/USB 安装，然后重试。 |

如果仍无法定位问题，请附上脱敏诊断报告、应用版本、手机型号、WebView 版本、复现步骤和预期行为提交 Issue；不要上传 Token、密码、真实服务器地址或媒体隐私信息。

## 当前限制

- 仅面向 RayNeo Air 系列配套设备与 ARM64 Android 环境；
- 当前 `targetSdk 29` 不满足 Google Play 的上架要求，以侧载为主；
- 暂不支持离线下载和播放列表编辑；
- 原生主播放器使用系统硬件视频解码器，不附带通用软件视频解码；不兼容媒体依赖 Jellyfin 转码；
- 自动发现只覆盖 IPv4 UDP，IPv6 端点需要手动输入。

后续范围与优先级见 [功能路线图](JELLYFIN_FEATURE_ROADMAP.md)。
