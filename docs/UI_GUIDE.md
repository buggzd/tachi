# 界面与交互维护指南

本文描述已实现的界面行为。日常操作见 [使用指南](USER_GUIDE.md)，会话、桥接与持久化契约见 [Android 架构](ANDROID_ARCHITECTURE.md)。

## 主题与观看偏好

手机「设置 → 界面外观」与眼镜侧栏的「设置 → 界面风格」提供两张可选择的预览卡。默认主题为液态玻璃
`liquid-glass`；`simpleUI` 使用相同的信息结构、导航和播放操作，以更轻量的
表面与动效呈现。选择会自动保存并同步到眼镜，重连、重启和退出账号后仍保留；
「恢复默认偏好」会恢复液态玻璃。

眼镜设置同时提供「小、标准、大、特大」四档字幕大小及中英文预览。字号选项仅在
设置页提供，播放器使用已保存的大小。手机设置使用相同选项，两端收到原生保存回执后同步更新。
标准档沿用原有字号；其余档位为 80%、125%、150%。此选项用于普通文字字幕；ASS/SSA 保留原有字号和排版，优先使用附带字体并以思源黑体回退。已固定在视频画面里的字幕不受影响。

![眼镜端设置与字幕大小预览](images/glasses-settings.png)

Liquid 手机端可在同一处选择或更换本机图片作为背景，也可恢复默认冰蓝背景。
图片只用于 Liquid 手机页面，触控板和 simpleUI 保持各自的背景；切回 Liquid
会恢复已选图片。设备卡使用液态玻璃、状态文字和官方眼镜预览。设备、设置与账号管理卡片统一使用浅色玻璃填充和细边高光。
「玻璃透明度」统一调整这些卡片、内部选项与底部导航，0% 为实底，100% 最通透，
默认 88%；边缘高光保留，文字和图标本身不变淡。默认背景也可调整，滑动即时生效并保存。

选择图片后点击「调整背景」，可设置 0–100% 透明度、屏幕/9:16/3:4/1:1/原图
裁切比例、1–3 倍缩放，并拖动图片或用方向键、位置滑杆定位。「界面预览」显示
裁切结果铺满手机窗口后的效果；图片固定于窗口，长页面不会拉伸图片。透明度
越高，图片越淡，100% 时只显示浅色底；默认 65% 接近原先的柔和效果。
点击「应用背景」后保存，取消或返回保留上次调整。

「文字配色」默认自动，也可固定为浅色或深色。自动模式结合裁切、透明度与
文字当前所在的背景区域选择明暗，标题、透明卡片及页面分组分别判断，滚动后
重新匹配，也计算玻璃透明度以及嵌套卡片的叠加底色。设置卡片里的标题、说明、
版本号和透明操作同样适配；明暗混合区域增加细描边与柔和阴影，避免文字融入图片。
登录表单、主题/遥控器示意图与实心控件保留各自的固定配色。
只在选图时生成一份小尺寸内存采样，后续使用这份数据；静止页面不持续采样。

Liquid 底部导航跟随玻璃透明度，保留玻璃细边和当前页短横线。中间触控键使用
不透明冰蓝渐变与固定深色圆点，并置于底栏高光之上，下层边框不会穿过按钮。
自定义壁纸下，导航文字沿用自动/浅色/深色配色，自动模式也考虑滚到导航栏下方的
玻璃卡片。simpleUI 继续使用实色导航。

## 设计

手机像一间温暖的展厅：暖白底色、石色拱形构图、细边框与灰绿色操作按钮。
眼镜像展厅中的放映空间：深炭灰背景、暖白文字、静止的主海报和清晰的细线焦点框。
海报、标题与留白构成主要层次，保留现有卡片、字号尺度与空间导航几何。
触控板支持纹理与纯黑背景，默认值随主题选择，规则见下文。

| 设计要素 | 手机 | 眼镜 |
| --- | --- | --- |
| 基础背景 | `#f3f0e9` 暖白 | `#141714` 深炭灰 |
| 面板 | `#faf9f5` 实色 | `#232920` 实色 |
| 正文 | `#2e322d` | `#f0eee6` |
| 强调 | `#475d49` 灰绿 | `#d5ddc6` 浅苔色 |
| 交互 | 轻微按压、短距离淡入 | 小幅抬升、暖白焦点框、淡入淡出 |

## 渲染开销控制

- simpleUI 在两端统一禁用 `filter`、`backdrop-filter`、阴影、混合模式和常驻
  `will-change`；规则覆盖交互状态、浮层与伪元素。液态玻璃继续使用原有样式。
- 手机卸载环境背景和 SVG 折射定义，停止按钮光学跟随的指针处理及待执行的 rAF。
  冷启动 simpleUI 不预加载玻璃装饰图，设备卡仍保留产品图。系统栏和 WebView
  底色也随主题更新。
- 眼镜首页在 Hero 区域聚焦时显示静止海报，焦点进入内容行后卸载背景海报。
  详情 Hero 封面不随焦点切换卸载，移到按钮、详情标签、剧集或相关推荐时保持显示，
  随页面正常滚动离开视口；其他浏览页面和登录/加载状态不挂载氛围背景。
  Hero 渐变跟随海报自身边缘，使用与页面相同的实色端点消除接缝。
- 遥控教学的人物和六种手势使用苔绿、暖灰配色的静态 SVG；颜色直接写入资源，
  无运行时滤镜，减少动态效果时也保持相同配色。成功反馈与六步教学逻辑保持一致。
  可运行 `python3 GlassesUI/scripts/prepare-tutorial-gestures.py --simple-ui-only` 从
  已提交的静态矢量重新生成 simpleUI 版本。
- 只为页面、操作和短暂反馈开启 `opacity` / `transform` 动画。常规过渡约
  140–240 ms；手势反馈在 520 ms 内结束。状态明确的加载图标可以旋转，静止页面
  不保留装饰性循环。尊重系统「减少动态效果」偏好。
- 主题不会降低视频刷新率、改变媒体解码或 HLS 参数，也不修改 SBS 的逐帧双眼合成。
  播放器保留单个视频和已有上报周期；普通文字字幕使用小面积深色底来保证亮画面上的可读性，ASS/SSA 保留自己的样式。

## 偏好与资源维护

| 偏好 | 保存位置与边界 |
| --- | --- |
| 主题、字幕字号 | 原生 `SessionRepository` 保存，通过现有状态字段同步两端；不重建 WebView、视频或媒体库 |
| 手机壁纸、裁切和文字配色 | 图片为 Android 私有 JPEG，参数由原生保存；只更新手机，不同步眼镜 |
| 玻璃透明度 | 原生独立保存 0–100 的整数，默认 88；更换图片、主题或账号时保留 |
| 遥控器背景 | 原生独立保存；显式选择后跨主题、账号和重启保留 |
| 眼镜 UI 音效 | 眼镜网页 localStorage；独立于原生“恢复默认偏好” |

`SharedUI/theme.mjs` 统一主题值，`SharedUI/simpleUI.css` 定义共同效果限制，两端自己的样式文件定义外观。原生消息白名单、图片尺寸限制和迁移规则以 [架构说明](ANDROID_ARCHITECTURE.md) 为准。

浏览器预览使用独立的预览存储；两个开发服务器 origin 不同，跨端同步应通过 `DevHarness` 验证。原生运行不保存另一份前端主题或壁纸副本。

背景图片、音效和教学 SVG 的源文件保存在两套前端的 `public/` 目录，必须提交到 Git。构建复制件由 Vite/Gradle 生成，不提交；详见 [构建指南](DEVELOPMENT.md)。

## 遥控器背景

「设置 → 外观与交互 → 遥控器背景」提供「纹理」与「纯黑」两种选择，适用于
两种主题，与 Liquid 的自定义手机图片互相独立。没有手动选择时保留各主题默认：
Liquid 使用纹理，simpleUI 使用纯黑。手动选择后，切换主题、账号或重启仍保留；
恢复默认偏好会回到 Liquid 与纹理。

纯黑模式的页面底色、播放/搜索面板底色、WebView、窗口和系统栏背景均为
`#000000`，关闭纹理、噪点、持续微光、手指光晕、装饰环、阴影与背景渐变。
必要的文字、边框、进度和手势提示仍会显示，轻触震动沿用自己的开关。
Android 10+ 的系统栏对比度遮罩也会关闭，避免把黑底抬成深灰。
系统键盘、通知等系统界面仍由 Android 管理。

OLED 的零亮度黑色像素可以停止发光；截图中的 RGB 0,0,0 能确认软件输出，
不能代替光学测量，也不能保证所有厂商的屏幕处理行为。此选项不会关闭整块屏幕，
可见控件区域仍会发光。

## 焦点、反馈与播放器

- 眼镜只有一个空间焦点，弹层打开时背景不接收输入；关闭弹层后返回触发按钮，方向导航跳过禁用控件。
- Liquid 首页内容行与详情选集的背景随遥控焦点更新；手机持有窗口焦点时，眼镜仍同步封面预览和首页 Hero/内容行状态，Mirror 2D 与 SBS 使用同一行为。复现及验收范围见 [焦点背景复测](performance/2026-09-16-focus-background/README.md)。
- 收藏、已看与续播状态由媒体数据驱动；已看卡片不再显示未完成进度。长标题省略，图片失败保留本地占位，加载失败有重试入口。
- 剧集详情的续播按钮以内部填充表示进度，显示具体集数与已看到的分钟、秒数；下方选集首次进入时定位最近观看集，并保留「看到这」标记。已看集的封面右上角常驻高对比勾选图标及「已看」文字，与最近观看位置分别展示；重看时保留已看状态。页面打开时保持 hero 可见，后续左右选集不反复跳回。两种主题使用相同数据与定位行为。
- 进度条聚焦且可拖动时，手机显示圆环；沿环顺时针快进、逆时针快退，角速度越高调整越多。同一次触摸可连续换向，反向时清除旧方向的余量和加速，首个整秒立即发送；停顿后继续转动无需重新激活。直线滑动保持原行为，环形手势松手不会额外确认或返回；离焦、隐藏、切集和触控取消会停用当前手势。圆环同时支持 Liquid、simpleUI 和纯黑触控板背景。
- 播放器区分准备、缓冲、暂停和错误；首帧前显示封面占位，播放中的缓冲保留当前视频。暂停换轨后继续保持暂停。
- 播放控制、上下滑动与面板操作的用户说明统一放在 [使用指南](USER_GUIDE.md)。视频信息面板只能展示 WebView 实际公开的数据，不能把源文件参数当成转码结果，或把硬件能力当成正在使用硬解的证明。
- 浏览页显示本地 `HH:mm` 时钟，采用紧凑字号和浅底框；播放器使用更小的辅助文字尺寸，只在顶部信息可见时显示。按分钟更新；页面隐藏或控件不活跃时停止定时更新。
- 动效尊重 `prefers-reduced-motion`。暂停不可见装饰须等待退出转场结束，重新显示时恢复；不得删去必要的输入、加载或状态反馈。性能约束见 [性能维护](PERFORMANCE.md)。

## 遥控教学

教学使用固定视角的练习空间：左侧展示动作、拇指 SVG 动画和反馈，右侧展示可操控的光点、目标及练习卡片。用户始终看眼镜，在手机触控板上操作。大约一分钟完成六个动作，没有倒计时或失败惩罚。

| 步骤 | 真实遥控输入 | 练习结果 |
| --- | --- | --- |
| 1–4 | 右、下、左、上滑动 | 光点沿四个目标移动，返回中心并解锁卡片 |
| 5 | 单击 | 打开虚构的「蓝色之外」详情卡片 |
| 6 | 快速双击 | 回到卡片列表，显示完成页 |

只有对应输入才能通过当前步骤。操作错误时，画面提示已收到的动作和预期动作。正确后保留 1.1 秒反馈，在这段时间内消耗连续输入，避免一个动作触发两关。方向指令来自既有的手机触控板识别，不另行实现第二套手势阈值。

首次媒体库就绪时显示欢迎页；支持稍后再学、双击暂停、退出以及侧栏重练。完成时保存 `lucent.remote-tutorial.v1=completed`，跳过时保存 `skipped`。本地存储不可用时仍能结束教学并继续浏览。重练从第一步开始，返回后恢复侧栏入口焦点；会话失效会卸载教学。

教学沿用唯一 WebView 的 2D/SBS 输出。场景只是 DOM 和 SVG，不创建播放器，不调用 Jellyfin 播放接口，不保存账号数据。提供减少动态效果时的静态接触姿态，避免依赖动画才能理解操作。

### SVG 来源与修改

手势源素材为用户提供的 `thumb-gestures-svg.zip`。Liquid 使用原始 3.2 秒 SMIL 动画与方向提示；减少动态效果时使用接触姿态的静态 SVG，simpleUI 使用重新配色的静态版本。

通过 `<img>` 加载单个动作，避免内联 SVG 的 ID 冲突。提交资源不得包含脚本、外部引用或栅格图片。常规构建直接使用已提交的 SVG，不需要原始压缩包。

如需从同一素材包重新生成：

```bash
python3 GlassesUI/scripts/prepare-tutorial-gestures.py /path/to/thumb-gestures-svg.zip
```

输出在 `GlassesUI/public/assets/tutorial/`；前端构建会复制到 Android 的本地资源目录。

独立浏览器预览入口为 Vite 的 `/?tutorial`；该入口不进入生产包。状态回归覆盖六步门槛、错误/连续输入、暂停/恢复、退出重练、键盘映射与存储失败。

## 界面音效

音源来自用户提供的 MORI 音效包，保留原始 48 kHz、16-bit PCM 立体声 WAV
及相对响度。文件位于 `GlassesUI/public/assets/sounds/`，随眼镜端 production
bundle 打包，运行时无需网络下载。手机前端不加载这些文件。

| 音效 | 交互 |
| --- | --- |
| focus / boundary | 遥控焦点实际移动 / 浏览导航无法继续移动 |
| select / back / home | 浏览页确认 / 返回 / 首页按钮 |
| open / close | 浏览页打开媒体卡片、设置、教学 / 关闭面板 |
| toggle-on / toggle-off | 浏览页开关；重新开启 UI 音效时使用 toggle-on |
| volume | 非零系统媒体音量的遥控调节，最长每 120 ms 一声 |
| success / error / notification | 操作结果 Toast 与教学反馈 |
| loading | 点击侧栏刷新媒体库，一次提示，不循环 |
| wake / sleep | 保留原始素材，当前没有对应的电视电源交互，不触发 |

「设置 → UI 音效」默认开启，关闭动作立即静音，不播放关闭尾音。
关闭开关只影响 UI 提示；影片音轨、音量、字幕和播放上报不变。偏好保存在
眼镜网页本地存储中，不随账号切换、退出登录或 WebView 重建重置。

播放器页面内不播放焦点、确认、返回、面板、开关、边界或错误等 UI 音效，
避免干扰影片声音；只有调节系统媒体音量时保留 `volume` 提示音。

音效池最多保留 14 个可用片段，同一时刻只播放一个，新的操作替换旧的提示。
同一种声音有 70 ms 防抖，音量为 120 ms。焦点停在顶部或其他边界时，连续的
同方向输入只提示一次；焦点移动、方向改变或重新进入该边界后才会再次提示。自动恢复焦点、
自动加载和前后台切换不发声。网页隐藏、销毁或关闭音效会中止活动片段；
资源或自动播放失败不会阻塞操作，也不会积压并延迟重放。
